# 怪啖论坛 · 站点数据快照

角色扮演企划「怪啖论坛」的站点数据镜像，用于异地备份与版本追溯。

## 结构

- `db.json` —— 用户档案、角色卡、怪谈档案、频道、帖子、聊天记录、留言板
- `files/` —— 角色卡整卡图、立绘、头像、音频等静态资源

`files/` 下的文件名就是站点访问路径。静态资源按一年 immutable 缓存，因此改图不会覆盖旧文件，而是换用新文件名，旧文件在此保留。

## 关于登录会话

`db.json` 的 `sessions` 字段在每次快照时被清空 —— 这是唯一被处理的数据，用于防止他人冒用登录态。其余字段与站点完全一致。

## 更新节奏

服务器整点自动快照并提交，一个提交对应一个时间点的站点状态。无变更时不会产生空提交。
